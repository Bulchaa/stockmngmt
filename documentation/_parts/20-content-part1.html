1 Getting Started

What is SOORA ERP?

SOORA ERP is a web-based business management system built for retail and service businesses in Ethiopia. It helps you run your whole operation in one place: manage your team and their permissions, build a product catalog, record sales orders, accept cash and Telebirr payments, send SMS receipts to customers, and track your income with reports.

The system is designed to be simple enough for everyday staff while giving owners full control with powerful reports and configurable settings.

Who is this system for?

SOORA ERP is built for any business that records orders every day and needs to know exactly where its money is — from one counter to many stores. It is especially made for businesses that use orders and order processing from start to finish.

🏪

Supermarkets, mini-marts, stationery, clothing and everyday shops that sell and record orders daily.

Especially for you: If your day is full of orders — from cash at the counter to Telebirr payments, from one bill to dozens — SOORA ERP is built around your way of working.

Installation Guide

Tip: This section is for the person who sets up the system (site owner or administrator). If you only use the system, just go to Logging In below.
  1. Download the files. Copy the project folder into your web server's root directory. For XAMPP this is usually C:\xampp\htdocs\ERP_qubeteck\.
  2. Create the database. Open phpMyAdmin and create a new database named stock.
  3. Import the schema. Import the stock.sql file into your stock database.
  4. Run the servers. Start Apache and MySQL from your server control panel (WAMP / XAMPP).
  5. Open the system. Visit http://localhost/ERP_qubeteck/ in your browser.

Configure the database connection (if needed)

If your database user or password is different (for example a production server), edit application/config/database.php:

database.php
$db['default'] = array(
    'hostname' => 'localhost',
    'username' => 'root',
    'password' => '',
    'database' => 'stock',
    'dbdriver' => 'mysqli'
    // ...
);
Important: Never run the system on a default password on the internet. Change the database and admin passwords before going live.

Logging In

  1. Open the system URL in your browser (for example http://localhost/ERP_qubeteck/).
  2. Enter your email and password on the login page.
  3. Click Login. You will be taken to the dashboard. If you were already logged in, the system opens the dashboard directly.
Default login (for first use — change it immediately):

3 User Management

Users are the people who log into the system (owners, cashiers, managers). Each user belongs to one group which decides what they can see and do.

Viewing users

Go to Users → Manage Users. The list shows users in a searchable table with columns for name, phone, gender and actions. The main administrator account (id 1) is never shown in the list and cannot be removed.

Adding a new user

  1. Go to Users → Add User.
  2. Fill the form:
    • Username — a short unique name used to identify the user.
    • Password — stored securely (hashed, never readable in the database).
    • Email — used to log in.
    • First name / Last name — the staff member's name.
    • Phone — contact number (also used if SMS is enabled).
    • Gender — Male / Female.
    • Group — choose the permission group for this user.
  3. Click Create. The password is hashed before saving. You will be returned to the user list.

Editing / deleting a user

  • Edit: click the Edit icon next to a user, change the details and save. You can also set a new password here — the confirmation field must match.
  • Delete: click the Delete icon. Only users with the "delete user" permission can do this.

Profile & Settings (your own account)

  • Profile — shows the details of the currently logged-in user. Always available to the logged-in user.
  • Settings — lets a user update their own information and change their own password (enter your current password logic: new password + confirmation must match).
Warning: Do not delete or disable the only user with administration rights — you could lock yourself out of the system.

4 Roles & Permissions (Groups)

A group is a set of permissions. Instead of giving permissions to each person, you create groups (for example Cashier, Manager, Owner) and assign users to them.

The 36 permissions

Every module has four standard permissions (create, view, update, delete) plus a few special ones. Examples:

PermissionWhat the user can do
createProduct / viewProduct / updateProduct / deleteProductWork with the product catalog.
createOrder / viewOrder / updateOrder / deleteOrderWork with orders and payments.
createUser / viewUser / updateUser / deleteUserManage staff accounts.
viewReportsSee sales charts and detailed income reports.
updateCompany / updateSettingChange company settings and system configuration.
createCustomer / viewCustomer / updateCustomer / deleteCustomerManage organization customers.

Permissions are checked on every action by the system. Even if a user navigates directly to a URL, they only succeed if their group has the permission.

Creating and managing groups

  1. Go to Groups → Add Group. Enter a group name.
  2. Tick the permissions you want this group to have. The list is grouped by module for easy selection.
  3. Save. The group appears in the group list and can be assigned to users.

You can edit a group's permissions at any time — the change applies to every user in that group immediately.

Cannot delete? A group that is assigned to at least one user cannot be deleted. Reassign or remove the users first.
Pre-configured groups: Two full-access groups are created for you: Administrator and Owners — both have all 36 permissions.

5 Product Catalog

The catalog holds everything you sell. It is organised with products plus supporting lists: brands, categories, stores and attributes. Products use these lists to describe themselves (a product belongs to a store, can have one or more brands / categories / attributes, and carries its own price and stock quantity).

Brands

Brands are the makers of your products (for example "Habesha", "Rico", "Samsung"). You can mark a brand active or inactive. Use Brands in the menu to add, edit or delete, and to set whether the brand is active.

Categories

Categories group your products into types (for example "Printing", "Stationery", "Clothing"). Manage them under Category. You can activate or deactivate a category, and products keep their category even if a list item is later made inactive.

Attributes

Attributes describe product options in two levels: an attribute (for example "Color" or "Size") and its values (for example Blue, Red / S, M, L). Create an attribute, then open it and click Add Value to add its values. Attribute values are stored with the product record (as JSON) so a product can carry several.

Stores

Stores are your locations or warehouses (for example "Chiro Main Shop", "Store 2"). Each product is assigned to a store. The dashboard shows the total number of active stores.

Adding and managing products

  1. Go to Products → Add Product.
  2. Enter the product details (name, SKU, price, quantity, image, description).
  3. Assign brand(s), category(ies), attribute value(s) and a store.
  4. Set availability and click Create.

Use Products → Manage Products to view the catalog. The list shows a thumbnail, SKU, name, price, quantity status (with low-stock colouring), store and availability. You can edit or delete products from here.
