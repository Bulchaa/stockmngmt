6 Orders & Sales

Orders are the heart of the system. There are two types: private / individual orders (customer information is typed into the order) and organization orders (linked to a saved customer record). Every order can hold several products, plus optional dimensions, discounts, service charge and VAT.

Order types

TypeDetail
Private / Individual OrderCustomer name, address and phone are entered directly on the order screen (menu: "Add Order").
Organization OrderLinked to a saved organization customer — you pick the customer and their details are pulled in (menu: "Add Organization Order").

Creating an order

  1. Choose the order type (Add Order for private, Add Organization Order for organizations).
  2. Select products. Add products to the order — for each one set the quantity; for measurement-based items (e.g. glass), enter the height and width and the area (kaaree) is calculated automatically.
  3. Set customer details (name, phone, address) — or pick an existing organization customer.
  4. Apply charges and discount — service charge and VAT/TOT are calculated automatically from the rates set in company settings. You can also enter a discount.
  5. Save the order. Stock is reduced automatically for every product sold, and an SMS receipt is sent if SMS is enabled.
Bill number: The system creates a unique bill number from the last 5 digits of the customer's phone plus a counter — for example 12344-0001.
Stock is automatic: Placing an order reduces product quantity. Editing an order restores the old stock and re-deducts for the new items, so your stock always stays accurate.

Viewing and editing orders

  • Manage Orders — lists all private orders (searchable table).
  • Manage Organization Orders — lists all organization orders.
  • Click Edit to change products, quantities, customer details or discounts. The order and its stock are recalculated.

Payments

Each order has a payment status and a payment history. You can record multiple payments against one order (useful for installments on loans).

Payment statusDescription
PaidThe order is fully paid.
Advance PaymentCustomer paid only part (advance/partial).
Loan / UnpaidNo payment yet — a credit/loan order (the dashboard tracks the total loan amount).

Payment methods: Cash, Bank Transfer, Mobile Transfer, and Telebirr. The order payment screen also lets you enter a Telebirr transaction number; the system can verify it automatically (see Telebirr Verification). When a payment is recorded, an SMS confirmation is sent if SMS is enabled.

                1 = Bank Transfer
                2 = Mobile Transfer
                3 = Telebirr

paid_status:    0 = Loan / Unpaid
                1 = Paid
                2 = Advance Payment

Order processing workflow

Orders move through three states. Use the Order Process page to update them.

StepDescription
Not ProcessedOrder received, work not started.

DeliveredOrder completed and handed to the customer.
  1. Open Order Process from the menu.
  2. Choose an order and set its status (Not Processed / Under Process / Delivered).
  3. Save. Each status change is recorded with the date, and a status-change SMS is sent to the customer if SMS is enabled.

Printing receipts

Every order can print a receipt/invoice. The receipt is optimized for thermal printers and uses your configured paper size (for example 80 mm wide x 297 mm). It prints automatically when the page opens and is written for your local audience (in Afan Oromo). It shows the bill number, customer, items, gross amount, service charge, VAT, discount and net amount.

9 SMS Notifications

The system can send SMS messages to customers automatically using the Ethiopian GeeSMS gateway. Messages are sent when an order is created, when an order status changes, and when a payment is received.

Setting up SMS

  1. Get a GeeSMS API token from geezsms.com/#/api.
  2. Go to System Configuration → Company tab.
  3. Enable SMS set the API token and (optionally) the shortcode ID.
  4. Click "Send Test SMS" enter a phone number and a test message to check that the API works.

When SMS is sent

  • Order created — confirmation to the customer.
  • Order status changed (process step updated).
  • Payment received — receipt/confirmation SMS.

Phone numbers are normalised to Ethiopian international format (for example 0911... → 25191...). If an SMS fails (bad credit, offline), the order still succeeds — SMS never blocks a sale.

SMS log

The SMS Log page shows every message sent: order/bill, phone, message text, type (order_created, status_change, payment), delivery status and the raw API response. Use it to diagnose undelivered messages.

GeeSMS API (REST)

10 Telebirr Payment Verification

When a customer pays with Telebirr, the system can verify the payment automatically by checking the official Ethio Telecom receipt page. This protects you against fake payment screenshots.

How verification works

  1. Customer pays via Telebirr and shares the transaction number (the 10+ digit TT number).
  2. Enter the TT number on the order payment screen.
  3. The system checks the receipt using transactioninfo.ethiotelecom.et and verifies that:
    • the transaction was found,
    • its status is Completed,
    • the payment was made today, and
    • the credited account matches one of your configured Telebirr accounts.
  4. Result is shown — verified, or a reason why not (not found / not completed / wrong account).
Verification status fields:
  • found — whether the receipt exists.
  • verified — found + completed + paid today + account matches.
  • account_matches — whether the credited account is in your account list.

Requirements

  • An Internet connection from the business server to Ethio Telecom.
  • Your Telebirr accounts added in Payment Accounts with category telebirr.
Note: Verification only confirms the payment reached one of your accounts today. Always also check that the paid amount matches the order total.

11 Reports & Analytics

Reports help you understand your income. You get both a visual yearly chart and a detailed, filterable list of every payment.

Monthly income chart

  • Shows total sales per month for a chosen year as a bar chart.
  • Choose the year from the dropdown (available years are listed automatically).

Sales detail report

  • Filter payments by a date range and see each payment record.
  • Columns include: bill number, customer name, customer type, datetime, total amount, paid amount, due amount, payment type and payment status.
  • Use it to see who still owes money (due amount > 0) and to reconcile cash, transfer and Telebirr payments.
Permissions: Only users whose group includes viewReports can open the reports pages.

Typical usage

  1. Open Reports → Income Report for the chart, or Sales Detail for the list.
  2. Pick the year or date range.
  3. Review/export — the detail table supports searching, sorting and pagination.
